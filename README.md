# PTRAP v2.0 - النسخة الكاملة

تمت إعادة بناء التطبيق بالكامل ليكون أكثر استقراراً وسرعة.

## التغييرات الرئيسية:
- **هيكلية نظيفة**: فصل المنطق البرمجي عن الواجهة.
- **تعدد اللغات**: دعم كامل للعربية، الإنجليزية، الإسبانية، والروسية.
- **تحسين قاعدة البيانات**: نظام أسرع لتتبع المخزون والمبيعات.
- **تصميم محسن**: استخدام الشعار الجديد وتناسق الألوان.

## التشغيل:
1. ثبت المكتبات: `pip install kivy kivymd pillow`
2. شغل التطبيق: `python main.py`

## بناء APK:
ارفع المجلد إلى GitHub واستخدم الـ Workflow المرفق سابقاً.
